🧩 快速开始开发插件

一个插件 = 一个目录，最少只需两个文件：

my-plugin/
  plugin.json      # 插件配置
  index.html       # 入口页面

plugin.json 最简结构：

{
  "name": "my-plugin",
  "title": "我的插件",
  "version": "1.0.0",
  "main": "index.html",
  "features": [{
    "code": "my-cmd",
    "explain": "命令说明",
    "cmds": ["关键词"]
  }]
}
