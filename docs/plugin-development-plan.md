## 一、AI Agent 配置管理器（ai-agent-manager）

### 定位

简化版的 cc-switch 风格工具，统一管理本地 AI Agent CLI 的各类配置，告别在多个工具间来回切换。

### 管理维度

| 配置类别       | 具体内容                                                                                             |
| -------------- | ---------------------------------------------------------------------------------------------------- |
| **AI 模型**    | OpenAI / Anthropic / DeepSeek / 本地 Ollama 等 provider 的 API Key、base URL、模型别名、默认模型切换 |
| **MCP Server** | 已安装的 MCP server 列表、启动参数、环境变量、启用/禁用开关                                          |
| **Skills**     | 各 agent 框架（Claude Code / OpenCode / Codex 等）的 skill 列表、启用状态、来源路径                  |
| **提示词**     | system prompt 模板库，支持变量占位、按场景（编码/写作/翻译）快速切换                                 |
| **Agent 框架** | 同时管理多个 CLI agent（Claude Code、OpenCode、Codex、ZCode 等），各自独立配置又共享通用资源         |

### 核心功能

1. **统一配置面板** — 一个界面查看/编辑所有 agent 的配置，不用手动找 JSON 文件
2. **一键切换** — 快速切换默认模型、默认 agent、默认 prompt
3. **配置导入/导出** — 备份、迁移、分享配置
4. **配置冲突检测** — 多 agent 框架共存时，端口/key/路径冲突提醒
5. **环境健康检查** — 检测 API key 有效性、MCP server 连通性、模型可用性

### 技术方案（待定）

- 读写各 agent CLI 的配置文件（`~/.omp/agent/`, `~/.config/opencode/`, `~/.claude/` 等）
- 通过 preload 脚本访问文件系统
- 数据存储：`ztools.dbStorage` 持久化用户的偏好设置和配置快照

## 二、OCR 识别工作流（ocr-workflow）

### 定位

快速初始化本地 OCR 环境，支持用户自定义识别规则和处理工作流，批量识别文档内容。

### 核心功能

1. **环境一键初始化**
   - 检测/安装本地 OCR 引擎（PaddleOCR / Tesseract / macOS Vision Framework）
   - 自动配置运行时依赖（Python 环境、模型下载）
   - 平台适配：macOS 优先用 Vision Framework（零配置），Windows/Linux 用 PaddleOCR

2. **识别规则配置**
   - 区域选择：框选图片/截图中的特定区域进行识别
   - 预处理规则：灰度化、二值化、去噪、旋转矫正
   - 后处理规则：正则提取、格式转换、模板匹配

3. **工作流引擎**
   - 流水线：截图/选图 → 预处理 → OCR 识别 → 后处理规则 → 输出
   - 支持串联多个处理步骤
   - 批量处理：文件夹拖入，自动遍历识别
   - 识别结果：文本输出 / JSON 结构化 / 导出为文件

4. **典型场景**
   - 发票识别：提取金额、日期、发票号
   - 表格识别：图片表格转 CSV/Markdown
   - 截图提取文字：快速 OCR 剪贴板图片
   - 批量文档数字化：文件夹级别的 OCR 批处理

### 技术方案（待定）

- macOS：优先使用 Vision Framework（系统原生，无需安装额外依赖）
- 跨平台：PaddleOCR（精度高，支持中英文）或 Tesseract
- 预处理：Sharp（Node.js 图像处理）
- 工作流定义：JSON DSL，存在 `ztools.dbStorage`

## 三、律师案件任务管理（lawyer-task-manager）

### 定位

面向律师的案件管理、日程安排、任务跟踪工具，轻量化、本地化、快速检索。

### 数据模型

```
案件 (Case)
├── 基本信息：案号、当事人、对方当事人、法院/仲裁机构、案由
├── 状态：进行中 / 已结案 / 归档
├── 日程 (Schedule)
│   ├── 开庭时间、举证期限、上诉截止、会见时间
│   ├── 提醒：提前 N 天/小时提醒
│   └── 关联：绑定到具体案件
├── 任务 (Task)
│   ├── 待办：准备证据、撰写文书、联系当事人、查档
│   ├── 优先级：紧急 / 高 / 中 / 低
│   ├── 截止日期
│   └── 状态：待办 / 进行中 / 已完成
└── 文档 (Documents)
    ├── 关联文件路径
    └── 备注
```

### 核心功能

1. **案件管理**
   - 案件列表：按状态、案由、法院筛选
   - 案件详情：一页看全案件信息、关联日程、待办任务
   - 快速创建：模板化新建案件（民事/刑事/行政/仲裁）

2. **日程管理**
   - 日历视图：按日/周/月查看开庭、会见等日程
   - 智能提醒：根据案由和程序阶段自动生成关键期限（如举证期限、上诉期）
   - 冲突检测：同一时段多个开庭自动预警

3. **任务管理**
   - 看板视图：待办 → 进行中 → 已完成
   - 任务模板：常见任务一键生成（如"一审开庭准备"自动生成：准备证据清单、撰写代理词、准备质证意见...）
   - 批量操作：结案时批量归档关联任务

4. **快速检索**
   - 全局搜索：案号、当事人姓名、关键词
   - 拼音搜索：中文姓名拼音首字母快速定位
   - 最近访问：高频案件置顶

### 技术方案（待定）

- 数据存储：LMDB（与 cc-ai-tools 宿主一致，高性能本地 KV）
- 日历组件：自研轻量日历视图或集成开源方案
- 提醒机制：Electron `Notification` + 系统通知
- 数据安全：本地存储，不上传，支持导出备份
